## 📌 项目背景与适配机型

“清屏”是一款轻量、免 Root 的现代安卓工具，专为解决当今 Android 生态中猖獗的**开屏 5 秒倒计时广告**、**误触诱导跳转**以及**摇一摇/扭一扭恶性广告**而设计。

本项目特别针对 **iQOO Neo 11** 及其搭载的 **vivo OriginOS 5 / 4 (Android 14/15)** 进行了深度软硬件特性与系统级保活适配：
- **屏幕与动效适配**：全面适配 iQOO Neo 11 的 1.5K/2K 144Hz 高刷直屏与中置挖孔屏，采用沉浸式状态栏与极简卡片 UI。
- **OriginOS 激进后台抗杀机制**：针对 vivo Jovi 智能省电引擎与后台冻结机制，内置专用的自启动、关联启动、后台高耗电及多任务卡片加锁引导通道。

## ⚙️ 安卓系统拦截原理、权限要求与功能边界分析

用户在需求中明确指出：**请先说明安卓系统下实现拦截所需的权限和限制，再给出能实际运行的方案，并明确哪些功能可以实现、哪些受系统限制。**

以下为深度技术剖析：

### 1. 实现拦截所需的核心权限与系统机制

| 权限 / 机制 | 系统标识 | 核心作用与原理 |
| :--- | :--- | :--- |
| **无障碍服务** *(核心必选)* | `BIND_ACCESSIBILITY_SERVICE` | 监听窗口状态变更 (`TYPE_WINDOW_STATE_CHANGED`) 与内容变化，实时检索节点树中的“跳过/关闭”关键词或控件 ID，触发点击或手势模拟。 |
| **前台守护服务** *(保活必选)* | `FOREGROUND_SERVICE_SPECIAL_USE` | 在系统状态栏常驻低调守护通知，提升应用进程 OOM 优先级（从后台 Cached 提升至 Foreground），防止系统随意杀进程。 |
| **电池优化白名单** *(保活必选)* | `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | 豁免系统 Doze 深睡模式和智能电量冻结。 |
| **开机自启动** *(保活推荐)* | `RECEIVE_BOOT_COMPLETED` | 监听开机完成与电源广播，重启后自动拉起前台守护服务。 |
| **悬浮窗权限** *(可选体验)* | `SYSTEM_ALERT_WINDOW` | 用于在跳过成功时弹出轻量级胶囊提示，或在开屏期间提供安全防误触遮罩。 |
| **获取已安装应用** | `QUERY_ALL_PACKAGES` | 提取产生广告的应用名称与高清图标，用于按 App 分类统计。 |

---

### 2. 明确功能边界：哪些可以实现？哪些受系统限制？

#### ✅ 能够完全实现的功能（当前版本已全部落地）：
1. **开屏广告毫秒级自动跳过**：
   - 支持多重正则智能文本匹配（“跳过”、“跳过广告”、“5s 跳过”、“关闭广告”、“Skip”等）。
   - 支持主流广告联盟 SDK 控件 ID 识别（腾讯优量汇 GDT、字节穿山甲 CSJ、快手联盟等）。
   - 支持坐标模拟手势点击（针对部分自绘或禁用 Clickable 属性的刁钻跳过控件）。
2. **按应用维度精准统计**：
   - 记录每次拦截的发生时间、所属 App、拦截类型。
   - 统计今日拦截次数、累计拦截次数、已保护应用总数、累计节省等待时间。
   - 提供各 App 独立拦截开关（白名单控制）。
3. **误触跨应用跳转拦截与自动返回**：
   - 当启动目标 App 在 3 秒内，若因误触被外部 Intent 突发跳转至电商平台（如淘宝、京东、拼多多、应用商店等），清屏能在 0.1 秒内感知到前台包名异动，并瞬间触发系统全局返回动作 (`GLOBAL_ACTION_BACK`)，将用户瞬间拉回原应用！

#### ⚠️ 受安卓系统底层沙箱限制的功能与解决方案：
1. **“摇一摇 / 扭一扭”加速度传感器的全局底层阻断**：
   - **系统限制**：在免 Root 纯无障碍模式下，Android 严格隔离进程，第三方 App **无法**跨进程阻断其他 App 读取手机陀螺仪/加速度计 (`SensorManager`)。
   - **清屏的应对方案**：
     - *极速跳过策略*：绝大多数摇一摇广告在开屏展示后需要 0.5~1.5 秒采样加速度数据。清屏在检测到开屏界面的 50ms~150ms 内瞬间完成跳过，直接摧毁开屏生命周期，从源头扼杀摇一摇的触发窗口。
     - *误触跳转自动返回*：万一因轻微晃动触发了跳转，清屏 0.1 秒内自动全局返回原 App。
     - *进阶（Root/Shizuku）*：如需底层彻底关闭特定 App 传感器，需借助 Shizuku 执行 `cmd appops set <包名> USE_BIOMETRIC ignore` 或 LSPosed 模块。
2. **系统“一键清理”与深度墓碑冻结**：
   - **系统限制**：国内定制 ROM（特别是 OriginOS、HyperOS）在用户点击多任务界面“垃圾桶/一键清理”时，会发送系统级 `killBackgroundProcesses` 甚至强杀无障碍进程。
   - **清屏的应对方案**：前台常驻服务 + OriginOS 专属保活配置（多任务卡片加锁 + 允许后台高耗电 + 开启自启动）。

## 📱 iQOO Neo 11 / OriginOS 专属保活配置指南

为确保清屏在 iQOO Neo 11 上不被系统自动关闭，请完成以下 4 个简单设置：

### 步骤 1：开启无障碍服务（若遇“受限设置”请解除）
1. 打开“清屏”，点击主界面的【无障碍: 点击开启】。
2. ⚠️ **特别提示（Android 13/14/15 官方安全限制）**：若系统无障碍列表中的“清屏”呈**灰色不可点击**：
   - 返回手机桌面，**长按**“清屏”图标 -> 点击【应用信息】；
   - 点击右上角的【三个点】菜单 -> 选择【允许受限设置】；
   - 输入锁屏密码验证后，重新返回开启无障碍即可。

### 步骤 2：允许自启动与关联启动
- 在清屏中点击【iQOO Neo 11 / OriginOS 深度保活配置】->【跳转自启动管理】；
- 找到“清屏”，开启**允许自启动**与**允许关联启动**。

### 步骤 3：允许后台高耗电运行
- 在设置中进入【电池】->【后台耗电管理】（或通过清屏一键跳转）；
- 找到“清屏”，选择【允许后台高耗电】（或无限制），避免深度休眠时被杀。

### 步骤 4：多任务后台卡片加锁（关键！）
- 从屏幕底部上滑并停顿进入多任务后台卡片视图；
- 找到“清屏”卡片，**向下滑动卡片**或点击卡片右上角菜单；
- 点击【锁定】图标（卡片右上角会出现小锁标记）；
- **效果**：锁定后，即使日常点击垃圾桶清理后台，清屏也会常驻运行，守护不中断！

## 🚀 编译与获取 APK

本项目已集成 GitHub Actions 持续集成。

### 方式一：直接在 GitHub Releases 下载
每当代码推送到本仓库主分支，GitHub Actions 会在云端自动编译并生成签名 APK：
- 前往仓库右侧的 **[Releases](https://github.com/ruyyyyan/CleanScreen/releases)** 页面；
- 点击最新版本 `v1.0.0`，下载附件中的 `CleanScreen-v1.0.0-iQOONeo11.apk` 即可直接安装到手机。

### 方式二：本地使用 Gradle 编译
```bash
# 赋予 gradlew 执行权限 (Linux/macOS)
chmod +x gradlew

# 执行打包 Release APK
./gradlew assembleRelease

# 产物路径
app/build/outputs/apk/release/app-release.apk
```
